How each piece behaves

What to check

  • Pace linesSeptember runs to today and stops with a dot. August and your average run the whole month, so you see where a normal month would land. Average is the mean of up to twelve prior months, as on every other page.
  • Summary lineCompares with August on the same day, the fairest mid-month comparison. The line ends at the Spent card's figure, since refunds are netted in both.
  • Not clickableThe chart only explains on hover. It is a line, and only heatmaps navigate (D20).
  • Attention orderPending first, then balances, then each category above its usual range, furthest above first. A kind with nothing to fix has no row.
  • Snapshot modeBalances need the API, so a read-only snapshot drops that row rather than guessing.
  • Row clickOpens the pane that clears it, and back returns here (D34).
